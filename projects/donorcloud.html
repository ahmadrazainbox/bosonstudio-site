DonorCloud

DonorCloud brings recurring donations, Gift Aid, Stripe payments, event ticketing and email campaigns together for UK charities. Built with Laravel and Vue.js.

The problem

UK charities and Community Amateur Sports Clubs run campaigns, events and Gift Aid across separate tools, and every unclaimed declaration is money left with HMRC.

DonorCloud set out to bring campaigns, donations, events, Gift Aid and donor relationships into one system that a small charity can run without developers.

How it was built

  1. 01

    One platform, many charities

    A multi-tenant Laravel and Vue 3 application, so every charity gets its own space on shared infrastructure.

  2. 02

    Gift Aid at the point of giving

    Declarations are captured when someone donates and claims are submitted directly to HMRC.

  3. 03

    Payments the charity controls

    Stripe recurring donations run through each charity's own Stripe account, so the platform never holds the funds.

  4. 04

    Events and outreach

    Event ticketing with QR validation, email campaigns, and AI-assisted fundraising agents built with the Laravel AI SDK.

Where it is now

  • Live for UK charities and CASCs at donorcloud.co.uk.
  • Free to start, with a 2.5% platform fee instead of a subscription.
